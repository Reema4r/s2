المسار:
- `task-manager/index.html`
- `task-manager/manifest.webmanifest`
- `task-manager/sw.js`
- `task-manager/icon.svg`

المزايا الحالية:
- واجهة عربية RTL متجاوبة مع iPhone والكمبيوتر
- تقويم شهري مع علامات ملوّنة للأحداث
- المواد الدراسية مع الواجبات والاختبارات والمنتدى
- مهام ومواعيد وتكرار
- حفظ محلي عبر LocalStorage
- PWA قابل للإضافة للشاشة الرئيسية
